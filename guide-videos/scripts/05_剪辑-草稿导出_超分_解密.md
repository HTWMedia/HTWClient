# 05_剪辑-草稿导出_超分_解密 教程文案

## 场景 1（约 0s 起）
- 旁白/字幕：草稿导出是用户需求最多的功能：把剪映或 CapCut 的草稿包上传，云端直接渲染成片，本机无需安装剪映。

## 场景 2（约 11s 起）
- 旁白/字幕：选择草稿 ZIP。这条演示草稿故意缺了部分素材，用来展示系统的素材核对能力。

## 场景 3（约 20s 起）
- 旁白/字幕：点击导出草稿，提交后系统先做素材核对：结果区明确列出缺失的素材类型、数量和文件名，并说明缺失部分会黑屏——按提示把素材补进包里重新上传即可。

## 场景 4（约 38s 起）
- 旁白/字幕：核对通过的部分继续云端渲染，进度实时显示，完成后直接下载成片。画面加速。

## 场景 5（约 46s 起）
- 旁白/字幕：超分：选择一条 960 乘 540 的小视频，目标设为 1920 乘 1080。

## 场景 6（约 56s 起）
- 旁白/字幕：点击超分，云端完成画质重建。画面加速。

## 场景 7（约 76s 起）
- 旁白/字幕：解密：新版剪映的草稿 JSON 是加密的，选择加密文件点击解密，瞬间返回明文内容，可直接查看或交给其他工具使用。

## 场景 8（约 89s 起）
- 旁白/字幕：剪辑面板六个功能全部演示完毕：粗剪、包装、剪同款负责生成，草稿导出负责渲染，超分负责增强，解密负责处理草稿文件。下一集看洞察与选题。
