## 每篇固定结构

1. **现象**：一句话说清用户/线上看到了什么（最好带真实报错原文）
2. **错误的第一反应**：我们最初以为是什么、为什么错了
3. **定位过程**：怎么验证、怎么排除（这一步是文章价值所在）
4. **修法**：贴关键代码（脱敏，不带真实地址/账号）
5. **怎么防止再犯**：加了什么测试/守卫
6. **收尾**：一句产品相关的话 + 仓库链接
