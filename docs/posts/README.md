# 分发清单（P1）

目标不是「更多人看到」，是**搜这个问题的人能看到**。所以标题一律用问题句，不用产品名。

## 三篇稿子

| 文件 | 面向的搜索意图 | 首发建议 |
| --- | --- | --- |
| `01-draft-to-video-without-jianying.md` | 「剪映 草稿 批量 导出」「不装剪映 导出视频」 | 掘金 / V2EX 分享创造 |
| `02-decrypt-jianying-draft.md` | 「剪映 加密草稿 解密」 | 知乎（长尾搜索最强）/ 掘金 |
| `03-multi-platform-publish.md` | 「多平台 一键发布 自建」「抖音 自动发布」 | 掘金（工程向）/ V2EX |

## 发布节奏（建议）

1. **先 02**：解密是最纯的搜索需求，竞争小，容易被收录；
2. **再 01**：主链路，承接 02 的读者；
3. **最后 03**：工程向，读者更挑剔，但转化最高。

每篇发完 3 天内不要重复投同一平台（会被判营销）。同一篇换个开头可投第二平台。
