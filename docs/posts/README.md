## 建议补的选题（按搜索价值排序）

这三类都能公开写、不带风险，而且都是真需求：

1. **「今天发什么」怎么用数据回答** —— 选题类。关键词「抖音选题」「对标账号 分析」，读者是日更创作者，正好是目标人群。
2. **爆款文案拆解怎么做成模板** —— 关键词「爆款标题 拆解」「小红书文案 结构」。可写成方法文，工具只做示例。
3. **四个平台一起发，坑在哪** —— 关键词「多平台发布 区别」「抖音 小红书 同步发」。比第 1 篇更工程向，转化最高。

## 发布节奏

一周一篇，不要连着发。同一篇发完 3 天内不要重复投同一平台（会被判营销）。

## 标题备选（A/B 用）

- 四个平台一起发，我踩过的 7 个坑
- 每天决定「发什么」的那半小时，能不能自动化

## 不要做的事

- 不要在同一段里堆「一站式」「全链路」「赋能」这类词——这正是上一版 README 被忽略的原因；
- 不要把 11 集视频当宣传素材往短视频平台搬，长合集在冷启动账号上拿不到量；
- 不要在文章里承诺「永久免费」「无限额度」，额度是按月的；
- 不要再写「不装剪映」「解密」「破解」这类标题。技术上做得到，不等于适合当成卖点写出来。
