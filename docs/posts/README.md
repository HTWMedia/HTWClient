### 第 1 步：用「剪映草稿解析」这类硬材料写第一篇公众号长文

竞品作者验证过的文章骨架：**痛点开场 → 一句话定义 → 能力拆解 → 适用场景与边界表 → 三行命令上手 → 前提与限制 → 结尾征集真实反馈**。标题不带产品名，靠问题句吃搜索长尾；文章会被第三方号自发转载，一次写作多次分发。

我们手里有他写不出来的素材（全部已有实跑证据，不需要新功能）：

- 官方 Web 草稿里滤镜的四个形态差异：位置、7 位短效果标识、`path`、独立滤镜轨；
- 「渲染成功 ≠ 有效果」：管道不报错也可能整段被云端静默跳过，必须按帧号抽帧做像素对照；
- 25 条精选滤镜逐条云渲染对照（25/25 生效）+ 26 段无滤镜噪声基线；
- 参数化调色的五个容器恒为空、接口无对应面板的否定取证；
- `examples/pyjianying-draft/README.md` 里可直接贴的命令与真实输出。

标题备选：**「草稿渲出来了，滤镜为什么没生效」**、**「剪映草稿里的滤镜，到底写在哪才有效」**。
⚠️ 必须避开「解密」「不装剪映」「绕过」「破解」这类词（11-06 整改口径）；JyDraft 的仓库描述仍含加解密字样，与本仓口径不一致，属待拍板项，**不要混用**。

## 建议补的选题（按搜索价值排序）

这四类都能公开写、不带风险，而且都是真需求：

1. **「今天发什么」怎么用数据回答** —— 选题类。关键词「抖音选题」「对标账号 分析」，读者是日更创作者，正好是目标人群。
2. **爆款文案拆解怎么做成模板** —— 关键词「爆款标题 拆解」「小红书文案 结构」。可写成方法文，工具只做示例。
3. **四个平台一起发，坑在哪** —— 关键词「多平台发布 区别」「抖音 小红书 同步发」。比第 1 篇更工程向，转化最高。
4. **剪映草稿形态考据（公众号向，第 1 步首选）** —— 关键词「剪映草稿 结构」「滤镜 不生效」。
   这是竞品作者验证过最能吃长尾搜索的题材，且素材全在手里：协议文档十节 + 25 条逐条像素对照 +
   示例 README 的实跑输出。写法见上面第 1 步，标题用问题句，避开禁词。
