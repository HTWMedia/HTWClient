### 准入门槛复核（2026-11-10 修正）

原先把「放量开关」当成一个总闸，把投放、仓库口径、短视频全部挂在它下面。复核后确认这样归类是错的：
**技术考据类内容的投放不属于放量推广**——第 0 步既已写明「修入口、回 issue、发技术考据都不等于开闸推广」，
成稿就不必等这个开关。按动作性质重新归类：

| 动作 | 是否需要拍板 | 依据 |
| --- | --- | --- |
| 04 发公众号、03 发掘金 / V2EX | **不需要** | 技术考据与工程复盘，属第 0 步明确的非推广动作；逐项复核标题与正文口径即可 |
| 仓库描述 / 话题加回搜索词 | **需要** | 唯一会改变对外门面表述的动作。11-06 主动撤回以留缓冲，改它等于改变风险敞口 |
| 群内推广 / 群发 | **需要** | 直接触达存量用户，属推广动作；群当前不活跃，优先级排在内容产出之后 |
| B 站单条短视频 | **不需要拍板，卡产能** | 需要拍摄与剪辑投入，与合规口径无关 |

结论：真正待拍的只剩两件——**仓库门面表述**与**群内推广**。前者是唯一的口径决策，后者要等群有内容可承接。
投稿与写稿因此不再串行，可同时推进。
