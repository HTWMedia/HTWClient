# 演进路线图 🗺️

公开版路线图，随版本更新。顺序按「对用户价值 × 实现成本」排，会随反馈调整 ——
有想要但没有的，直接开 Issue 描述你的场景。

> 关于形态：服务端保持托管，不做开源 / 自部署 —— 转写、渲染、发布都吃算力，
> 托管才能保证体验一致。开源的是客户端与 Agent Skills，你能审阅、能改、能自己接。
> AuthKey 是防流量攻击的准入闸口，新用户注册即送 **1 个月免费额度**（到期可续）。
