# 30 秒演示 GIF 分镜脚本 🎬

目标：一条 <8MB 的演示 GIF，让访客在 30 秒内看懂 HTWClient 的完整闭环。
放在 README「界面预览」最上方，转化率远高于静态截图。

## 录制准备

- 工具：[ScreenToGif](https://www.screentogif.com/)（Windows，免费）或 [Kap](https://getkap.co/)（macOS）
- 参数建议：窗口宽度 ≤900px、**12~15 fps**、输出 GIF ≤8MB（超过就降 fps 或砍分镜）
- 录制前：准备一个 B 站热门视频链接、一段 30 字左右的主题描述；关闭无关窗口与通知

## 分镜（共 30 秒）

| 时间 | 画面 | 操作 / 说明 |
| ---- | ---- | ---- |
| 0-3s | 工作台全景 | 鼠标从左到右划过五个能力面板，展示「一站式」布局 |
| 3-8s | 媒资洞察 | 粘贴一条 B 站视频链接 → 点击分析 → 报告逐段生成（标题/标签/钩子拆解） |
| 8-15s | 内容创作 | 输入主题「低卡减脂餐」→ 勾选调研与素材搜索 → 进度日志滚动 → 成片脚本生成 |
| 15-22s | 智能剪辑 | 上传素材 → 粗剪（设定 15-30s）→ 成片预览播放 2 秒 |
| 22-30s | 多平台发布 | 勾选抖音 / 小红书 / B 站 → AI 生成文案与封面 → 点击发布 → 三个平台全部 ✓ |

## 录制技巧

- 每个分镜**先摆好画面再开始录**，剪掉无操作的时间段；
- 鼠标移动放慢、单击代替连击，观众要跟得上；
- 关键结果出现时（报告生成、发布 ✓）**停顿 1 秒**再切换；
- 导出后用 [ezgif.com](https://ezgif.com) 压缩一遍（lossy 80 左右还能再砍 30% 体积）。
